# Specimen 001 Visual Language

| Role | Specimen value | Observable use | Redundant cue |
|---|---:|---|---|
| Action / affirmative / live | `#A2FF00` | primary actions, live states, selected reel | border, text label, pressed state |
| Information / technical | `#00E5FF` | technical badges, metric slab, focus outline | label text, terminal framing |
| Expressive emphasis | `#FF007A` | ribbons, review form, high-attention surface | position, border, copy |
| Annotation / selection | `#FFE600` | brand sticker, metadata, read action | border, text, selected state |
| Infrastructure / authority | `#000000` | terminal panels, borders, physical shadow | structural location, monospace text |
| Document / neutral field | `#F4F0EA` / `#FFFFFF` | page canvas, cards, reading surface | whitespace and boundary treatment |

These hues are specimen values, not universal Neo-Brutalist requirements. The candidate reusable layer is semantic role and contrast relationship.
